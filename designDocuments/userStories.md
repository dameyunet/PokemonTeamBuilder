# User Stories

## MVP User Stories

### User Authentication & Account Management

#### Sign up *

New users want to be able to add and save pokemon data.

#### Sign In *

As a registered user I want to log in so that I can add, edit or remove pokemon data.

#### Password Reset *

As a registered user or admin user, I want to be able to be able to reset my password if I forget it.

### Pokemon Search & Filtering

#### Find Pokemon by Name *

As a registered user I want to be able to find pokemon by name so that I can learn more about those pokemon.

#### Find Pokemon by typing *

As a registered user, I want to filter pokemon by typing.

### Pokemon saving and editing

#### Add pokemon to saved team *

As a registered user, I want to be able to add a pokemon to a saved to for quick access.

#### remove a pokemon *

As registered user, I want to be able to remove a pokemon from saved team.

### Admin & Data Management

#### Admin Edit pokemon *

As an admin user, I want to be able to edit any saved teams.

#### Admin Delete pokemon *

As an admin user, I want to be able to delete any pokemon from saved teams.

---
#### View Photos of pokemon *

As a registered user I want to see a photo of the saved pokemon on each team.

*Denotes MVP
